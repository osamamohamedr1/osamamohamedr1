## About me

I'm a **Flutter Developer at InTheKloud**, building production fintech and e-commerce apps for iOS and Android: live gold prices streamed over **SignalR**, **Paymob** and **SkipCash** payments, and merchant tools people use every day. I take features from the first commit to **App Store** and **Google Play** releases, and my **C# / .NET** backend experience means I speak the API team's language.

- **Currently:** Flutter Developer @ InTheKloud (fintech & e-commerce)
- **Focus:** Clean Architecture · BLoC / Cubit · real-time with SignalR · payments
- **Backend:** C# · .NET · ASP.NET Core · SQL Server
- **Open to:** full-time & freelance Flutter work
- **Based in:** Egypt · Arabic (native) · English (professional)
